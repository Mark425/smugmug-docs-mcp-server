# SmugMug Docs MCP Server

This project creates a lightweight TypeScript MCP server that wraps the SmugMug API reference docs over stdio.

## Tools

- `search_smugmug_docs(query)`
- `fetch_smugmug_doc(input)`

## Setup

```bash
npm install
npm run build
npm start
```

## VS Code

The workspace includes a VS Code MCP configuration in `.vscode/mcp.json` so the server can be launched from the workspace.
